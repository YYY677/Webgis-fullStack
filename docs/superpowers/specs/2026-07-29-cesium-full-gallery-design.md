# Cesium 全量章节画廊设计

## 目标

将 Cesium 学习入口调整为按文件顺序浏览的全量章节画廊。`/cesium-demo` 展示现有 14 个章节卡片；侧栏重新展示学习首页与全部章节，不再显示专题入口。已有章节 URL 保持不变。

## 信息架构

1. 学习首页按 `01` 到 `14` 的文件与路由顺序平铺卡片，不分专题。
2. 桌面端内容区为三列卡片网格；中等宽度降为两列，移动端降为一列。
3. 每张卡片包含 16:9 实景封面、编号、标题、简述和关键 API 标签。
4. Cesium 侧栏包含学习首页和全部 14 个章节；菜单自身滚动，主内容不受挤压。

## 路由与文案

Cesium 父级路由显式承载子级 `RouterView`，确保 `/cesium-demo` 和全部 `/cesium-demo/*` 页面都在 `MainLayout` 主内容区渲染。

章节名称采用以下面向学习目标的描述：

| 编号 | 标题 |
| --- | --- |
| 01 | Viewer 与场景初始化 |
| 02 | 坐标转换与相机方位 |
| 03 | 屏幕空间事件 |
| 04 | Entity 图形与属性 |
| 05 | Primitive 与几何实例 |
| 06 | 数据源与三维数据加载 |
| 07 | Cesium3DTileset：加载、样式与拾取 |
| 08 | Clock 与动态 Entity 轨迹 |
| 09 | Entity 交互绘制与量算 |
| 10 | 地形采样与空间分析 |
| 11 | Entity 动态材质 |
| 12 | Model 与 3D Tiles 的 CustomShader |
| 13 | Primitive 与 Appearance |
| 14 | Scene 环境与出图 |

## 快照策略

封面保存到 `frontend/public/cesium-data/lesson-thumbnails/`，由学习首页以静态路径加载。截图均来自本地实际运行的页面，不使用占位图或生成图。

- 使用固定的桌面视口和 16:9 裁剪。
- 等待页面核心资源、对象和效果加载完成后再截图。
- 截图选择能同时表达章节核心 API 与最终可见效果的状态；交互类页面先完成一次代表性操作。
- 画面以三维场景为主，只有在理解内容需要时保留少量控制面板。

## 边界

- 不删除既有 Cesium 示例页面、专题组件或原有章节 URL。
- 不增加后端接口、学习进度或搜索功能。
- 封面仅用于首页，不改变各示例的生命周期与交互逻辑。

## 验收标准

1. `/cesium-demo` 主区域显示 14 张、按 01–14 排序的可点击卡片。
2. 侧栏显示学习首页与全部 14 个章节，且当前章节保持高亮。
3. 15 个 Cesium 路由入口（首页加 14 章）均可渲染正确页面。
4. 每个卡片使用对应的实景快照；无缺失或占位封面。
5. 目标测试、全量测试、生产构建与浏览器导航验证通过。
