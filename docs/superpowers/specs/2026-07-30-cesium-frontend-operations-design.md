# Cesium 前端业务操作专题设计

## 目标

在已有 01 至 14 课的基础上，新增三个只依赖浏览器与 Cesium 前端 API 的学习页面：图层组织、客户端标绘编辑和场景性能治理。它们面向企业 WebGIS/三维 GIS 的高频前端职责，不接入任何后端接口、持久化、权限或协同能力。

章节连续编号为 15、16、17；07 保持现状，09 保持“交互绘制与量算”的基础定位。

## 章节与边界

| 编号 | 页面 | 学习目标 | 明确不做 |

## 15：图层体系与图层树管理

Cesium 没有可直接复用的统一“图层树”。页面维护一个前端树节点模型；每个叶节点持有或定位一个 Cesium 对象，通过适配逻辑把 UI 操作同步到实际集合。

### 展示对象

1. 底图与一个可叠加的影像图层，使用 `viewer.imageryLayers`，展示 `show`、`alpha`、`raise/lower` 和移除。
2. 一个本地 GeoJSON `DataSource`，使用 `viewer.dataSources`，展示 `show`、定位和移除。
3. 一个用于演示标记的 `CustomDataSource`/Entity 集合，说明业务 Entity 应按数据源分组，而不是散落在全局 `viewer.entities`。
4. 已有本地建筑 `Cesium3DTileset`，使用 `scene.primitives`，展示显隐、定位与移除。

### 交互与清理

- 树节点提供显隐开关；可操作叶节点提供类型适配后的属性控件。
- 选中节点可 `flyTo` 到其可定位对象；无法可靠定位的节点不展示该动作。
- 移除后，页面从前端树和对应 Cesium 集合中同步删除；支持重新添加演示图层。
- 每个页面自行创建的对象都记录在可清理注册表中；组件卸载时按对象所属集合移除，再销毁 Viewer。
- 不复用全局底图切换器的“清空所有影像”策略处理业务叠加层，避免误删当前课的演示图层。

## 16：前端标绘编辑与 GeoJSON 导出

本页是 09 的后续课：09 讲如何绘制和量算；16 讲完成后如何把要素维护为可编辑的前端业务对象。

### 数据模型与交互

- 内存中的 `Annotation` 模型保存稳定 id、名称、类型、样式、顶点经纬度和对应 Cesium Entity。
- 支持画点、折线和多边形；预览阶段使用动态属性，完成后转为受模型驱动的可编辑对象。
- 点击选择要素，显示顶点控制点；拖动控制点更新模型和图形，拖拽期间临时禁用相机旋转/平移，结束后恢复。
- 侧栏可删除当前要素、清空全部要素、显示已选要素的基础属性；不把这些动作称为后端 CRUD。
- 拾取位置按 `pickPosition`、地形相交、椭球相交依次降级，兼顾 3D Tiles、地形和纯椭球场景。

### 导出

- 点击导出时，在浏览器端生成并下载 GeoJSON `FeatureCollection`，不发起网络请求。
- 坐标采用 WGS84 经度、纬度顺序；贴地标绘默认输出二维坐标，避免把未验证的贴地高度当作业务高程。
- 要素 id、名称、类型与必要的展示样式写入 `properties`，便于后续接后端时建立清晰的数据边界。

## 17：性能优化与资源生命周期

页面用可观察的小型场景说明真实工程中的常用治理点，而不是制造不可靠的机器跑分。

### 渲染模式

- 提供连续渲染与 `scene.requestRenderMode` 的切换。
- 所有由 Vue 控件、定时外部数据或异步结果引起的场景变更，都通过统一入口调用 `scene.requestRender()`。
- 使用 `postRender` 只统计“本次实际绘制完成”的次数，明确它不是触发下一帧的入口，避免在其中无条件请求渲染。

### 生命周期

- 页面维护一次性清理注册表，集中管理 `ScreenSpaceEventHandler`、Cesium `Event` 监听取消函数、计时器、尚未失效的异步结果及临时场景对象。
- 卸载时先停止事件和异步写回，再从集合中移除页面对象，最后调用 `viewer.destroy()`；所有销毁路径保证可重复调用。
- 演示静态对象、动态对象和临时预览对象的差异：静态内容不持续写入，动态内容按真实更新频率触发渲染，临时对象在操作结束后移除。

### 企业实践清单

页面说明并对应实际 API 演示以下原则：按需渲染、避免每帧更新 Vue/Entity、批量或分组管理对象、及时移除不可见业务结果、取消事件监听、在路由切换时销毁 Viewer、使异步加载结果可失效。

## 验收标准

1. 学习首页显示连续的 01 至 17 课，15、16、17 可由目录和直接 URL 进入。
2. 15 能同时管理至少一类影像、数据源、业务 Entity 分组和 3D Tiles，且移除不影响不属于该课的对象。
3. 16 可在浏览器内完成创建、选择、顶点拖拽、删除并下载可解析的 GeoJSON 文件；全过程无 API 请求。
4. 17 在显式渲染模式下，控件和外部状态变化后仍能正确更新；页面卸载不遗留事件处理器、计时器或未销毁 Viewer。
5. 新增纯数据/生命周期工具具备单元测试；全量测试与 `npm run build` 通过；交互页进行浏览器端人工验证。
