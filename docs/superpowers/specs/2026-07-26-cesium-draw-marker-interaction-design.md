# Cesium 绘制标记与完成交互设计

## 目标

修正第 09 章中绘制点被地形遮挡的问题，并支持右键或双击完成折线、多边形绘制。

## 决策

- `activePositions` 始终保存拾取到的真实地表或模型表面坐标，用于距离、面积计算和贴地几何。
- 标记 Entity 使用真实坐标向外抬高 2 m 后的位置，避免在 `depthTestAgainstTerrain` 开启时被地形切掉。
- 拾取按 `scene.pickPosition`、`scene.globe.pick`、`camera.pickEllipsoid` 的顺序降级：优先获得场景深度位置，其次获得真实地形表面，最后才使用没有地形高度的椭球面。
- 双击完成时移除连续重复的末点，避免两个 `LEFT_CLICK` 与一个 `LEFT_DOUBLE_CLICK` 共同触发后留下重叠顶点。
- 保留地形深度检测；不使用无限距离的 `disableDepthTestDistance`，避免标记穿透山体或模型。

## 验收标准

- 绘制点和顶点在地形上方完整可见。
- 折线和多边形可由右键或双击完成；双击不会留下重复末点。
- 面板说明与关键逻辑注释能解释拾取、抬高、预览和事件清理的职责。
- 既有量算单元测试与生产构建通过。
