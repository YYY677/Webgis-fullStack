# WebGIS Atlas UI 视觉改造设计

## 目标

将登录页、dashboard 与应用外壳统一为“深海测绘台”风格，消除 dashboard 中央区域的空白感；保留四个学习组及其组内页面的路由、内容和交互。

## 范围

- 改造 `frontend/src/pages/login/index.vue`：地图网格氛围、品牌区、清晰的登录表单与入场动效。
- 改造 `frontend/src/pages/dashboard/index.vue`：以空间态势区作为主视觉，提供四个学习组入口与模块状态。
- 改造 `frontend/src/layout/MainLayout.vue`：统一侧栏、顶栏、搜索弹窗与页脚外观，不改菜单的数据来源和路由逻辑。
- 补充应用级设计 token、Motion 与按需图标配置。

## 排除项

- 不修改四个学习组内部教学页面、地图逻辑、接口、认证流程、后端与 GeoServer 配置。
- 不将现有 Element Plus 图标全量替换；仅为新页面和外壳使用统一的 Tabler 图标。

## 设计系统

| Token | 值 | 用途 |
|---|---|---|
| 深海底色 | `#07111f` | 页面与地图背景 |
| 深层表面 | `#0d1b2d` | 侧栏和面板 |
| 青色主色 | `#55d6ff` | 焦点、路径和主要操作 |
| 琥珀强调 | `#f2b86b` | 坐标、提示和状态强调 |
| 成功色 | `#68e0ae` | 正常运行状态 |
| 正文 | `#eaf5fb` | 高对比文字 |
| 次级文字 | `#8ea8bb` | 标签与说明 |

登录页使用全屏网格与轮廓线作为背景，表单保持明亮、易读。dashboard 使用带网格、等高线、坐标及状态的空间态势区承载欢迎信息；四个学习组只以入口卡片呈现，卡片路由到既有首页。

## 交互与可访问性

- 登录提交、主题切换、菜单、搜索与退出登录沿用现有逻辑。
- Motion 仅用于入场和悬停反馈；遵从 `prefers-reduced-motion`。
- 图标仅传达已有操作含义，保持可读文字；按钮与入口保留键盘焦点。
- 小屏幕下侧栏收窄、状态区与入口卡片折行，避免横向溢出。

## 验收标准

1. `/login` 和 `/dashboard` 呈现统一深海测绘视觉，中文文案正常显示。
2. dashboard 中央区域不再是简单空白与单行文本，四个既有学习组可从入口卡片打开。
3. 原有菜单、主题切换、搜索、退出登录与登录跳转继续可用。
4. 前端构建通过，并通过浏览器检查桌面与移动视口。
