# Cesium 学习目录设计

## 目标

将 Cesium 示例从不断增长的章节侧栏改为专题式学习目录。学习首页负责选择学习方向，专题页负责浏览章节，既有 14 个示例页面及其 URL 保持不变。

## 信息架构

学习入口为 `/cesium-demo`，展示 5 个专题卡片。每张卡片包含专题名称、简介、章节数量和代表章节；点击后进入 `/cesium-demo/topic/:topicId`，展示该专题的完整章节列表。原有示例继续使用其现有 URL，例如 `/cesium-demo/cesium-entry`。

| 专题 ID | 专题名称 | 当前章节 |
| --- | --- | --- |
| `fundamentals` | 基础与坐标 | 01、02 |
| `objects` | 对象建模与绘制 | 04、05、09 |
| `data` | 数据与三维瓦片 | 06、07 |
| `interaction` | 交互、时间与空间分析 | 03、08、10 |
| `rendering` | 渲染与视觉效果 | 11、12、13、14 |

新增章节必须归入一个专题；只有无法表达为上述五类时，才新增专题。

## 页面行为

- 学习首页使用响应式卡片网格，宽屏展示 3 列，窄屏降为单列。
- 专题页展示专题说明、章节数量、返回全部专题入口和章节卡片。
- 章节卡片跳转至已有页面；既有页面不嵌入新组件、不修改其 Cesium 生命周期。
- Cesium 侧栏只展示“学习首页”和五个专题入口；其它菜单维持原有渲染和行为。
- 当前处于某个 Cesium 章节时，侧栏仍可通过该章节归属的专题进入目录；不在侧栏平铺章节。

## 数据与边界

新增 `cesium-learning-catalog.ts` 作为专题、章节元数据的唯一来源，提供专题查询和章节归属查询。路由继续定义页面组件与既有 URL，目录元数据仅保存面向展示的名称、摘要和 URL。

不引入后端、搜索、进度记录、权限变化或新 UI 依赖。

## 验收标准

1. `/cesium-demo` 与五个专题页均可导航至对应既有章节。
2. 当前 14 个 Cesium 章节全部且仅归入一个专题。
3. Cesium 侧栏不再直接列出全部章节，其他功能模块侧栏不受影响。
4. Vitest、生产构建和浏览器端导航验证通过。
